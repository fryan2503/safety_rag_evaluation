# Long-Context Run Archive

This directory stores accepted long-context runs grouped by run id.

Each run folder uses:

- `raw/` for raw batch payloads and raw JSONL outputs
- `parsed/` for parsed judge CSV/JSON outputs
- `rag/` for raw long-context outputs and metrics-enriched CSVs
- `merged/` for promoted merged CSVs
- `analysis/` for plots and summary text
- `meta/` for manifests, batch ids, and notes
